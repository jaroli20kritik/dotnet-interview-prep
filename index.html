Scenario

A DB2 column can be NULL. How do you handle it in C#?

Interview answer · English

A DB NULL comes back as DBNull.Value, not C# null, so a direct cast throws. I map nullable columns to types like decimal? and check for DBNull when reading.

Samjho · Hinglish

Database ka NULL aur C# ka null alag cheezein hain. Seedha cast karoge to exception aayega, isliye pehle check karo.
